# Text Analyzer

## Описание проекта

Text Analyzer — это консольная программа на Python для анализа текста.

Программа позволяет:
- вводить текст вручную;
- читать текст из файла;
- считать количество символов;
- считать количество слов;
- считать количество предложений;
- находить наиболее часто встречающиеся слова.

## Выбранная методология

Для разработки проекта использована итеративно-инкрементальная методология.

## Обоснование выбора методологии

Итеративно-инкрементальная методология была выбрана потому, что задача легко делится на отдельные функциональные блоки.  
Каждый блок можно реализовать и проверить отдельно:

1. Ввод текста.
2. Обработка текста.
3. Подсчёт статистики.
4. Вывод результата.
5. Тестирование.

Такой подход позволяет постепенно создавать рабочую программу и улучшать её функциональность.

## Этапы работы

1. Анализ требований.
2. Декомпозиция задачи.
3. Проектирование структуры программы.
4. Реализация функций ввода текста.
5. Реализация функций анализа текста.
6. Проверка работы программы.
7. Подготовка документации.

## Применённые методы

В проекте использованы следующие методы:

- метод анализа требований;
- метод декомпозиции;
- метод алгоритмизации;
- метод структурного программирования;
- методы обработки строк;
- метод регулярных выражений;
- метод частотного анализа;
- метод функционального тестирования.
